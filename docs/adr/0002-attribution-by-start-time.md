# ADR-0002：跨零点能量按区间开始时刻归属

- 状态：已采纳（2026-10-04）
- 前置决策：[ADR-0001](0001-natural-day-period.md)

## 背景

控制指令与电表计量都按区间（一拍）发生：`[start, end)`。一拍通常是
秒级到分钟级，但跨零点那一拍横跨两个自然日。对这一段能量有两种
归属算法：

- **按开始时刻归属**：整段计入 `start` 所在自然日；
- **按结束时刻归属**：整段计入 `end` 所在自然日。

两者每天只差跨零点那一拍，但月结时差额会逐月累加；如果不选定一种，
配额台账、峰谷结算、电表日冻结三方永远对不上。

## 决策

**配额与日额度归属一律按区间开始时刻**：`[start, end)` 整段计入
`start` 所在自然日，包括物理上发生在零点之后的尾段。

实现上（`batterystore/quota/interval.py`）：

- 能量分片的 `day_key` 统一取区间开始日，**零点不作为切分点**，因此
  跨零点一拍是一个分片，不会把一半能量记到新的一天；
- **峰谷档是另一件事**：电费按物理交付时刻积分，跨 08:00/22:00 的
  能量按时长比例（或电表分段读数）切开，各按各的电价。归属日唯一、
  电价档按物理时间，两者不混用一条规则。

## 理由（为什么选开始时刻而不是结束时刻）

1. **事前控制必须在开始前知道额度**：超额拒绝发生在功率下发之前
   （预检在 `start` 时刻执行）。按开始时刻归属，预检、扣减、日后对账
   三者检查的是同一个自然日的剩余额度；按结束时刻归属，预检时要猜
   "结束日的额度"，而结束日的台账此刻尚不存在，控制逻辑无法自洽。
2. **与"拒绝保持上一个有效功率"兼容**：指令在开始时刻被准入后，
   后续不因跨过零点而改变这笔账的归属，PCS 也不需要在零点瞬间为
   记账原因中断当前这一拍。
3. **确定性可重放**：归属只依赖 `start` 与固定日历，重放同一批计量
   数据永远得到同一结果，满足 [ADR-0003](0003-append-only-archive.md)
   的归档不可改写要求。
4. **月结差额可控且方向固定**：开始时刻口径只在每天一拍、每月至多
   几十拍上与结束时刻口径不同；差额方向恒为"零点后尾段记前一天"，
   可逐笔列示，不会在月与月之间振荡。结束时刻口径同样固定，但其
   "记账日晚于交付日"与日初额度控制冲突（见第 1 点）。

## 被否方案

- **零点两侧物理切分、分别归两天**：会计上"精确"，但把一拍能量拆到
  两个配额日，事前预检无法对单一日额度做判断；且一拍的物理切分依赖
  表计是否提供分段读数，没有读数时只能按时长摊分，反而引入估算量。
  保留这种切分仅用于**峰谷电价档**（电价本身按物理时间定义）。
- **按结束时刻归属**：与事前配额控制冲突，见理由 1。

## 后果

- 23:59–00:01 的一拍整段计入旧自然日；新自然日的额度从它开始后的
  第一拍起用。
- 零点后才完成计量并上报的旧拍，作为**迟到分片**追加到开始日台账，
  规则见 [ADR-0003](0003-append-only-archive.md)。
- 与电表日冻结值对账时，跨零点一拍是唯一预期差异点；差异用差异
  说明追加，不回滚、不改账。
